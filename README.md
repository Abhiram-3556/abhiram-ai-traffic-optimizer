# AI Traffic Optimizer

AI-based software-only traffic flow optimization project.

## Features
- Webcam/video input
- Vehicle detection
- Traffic density estimation
- Adaptive signal simulation
- Dashboard visualization

## Project Structure
traffic-ai/
├── app.py
├── detector/
├── predictor/
├── optimizer/
├── dashboard/
├── data/
└── requirements.txt

## Run
pip install -r requirements.txt
streamlit run app.py
